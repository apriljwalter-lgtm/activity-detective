Where the mistakes happen

Rows: what people were really doing. Columns: what the model predicted. The biggest problem: climbing stairs mistaken for walking.

Ask the chatbot

Type any question about the data, model, or results. A small language model runs entirely in your browser (WebLLM + WebGPU) and answers only from the site guide. Pick a model below: the first load downloads 0.4–0.9 GB, and later visits use your browser's cache.

Data: Human Activity Recognition Using Smartphones, UCI Machine Learning Repository (Anguita, Ghio, Oneto, Parra & Reyes-Ortiz, 2013), licensed CC BY 4.0. We use the walking, walking-upstairs and walking-downstairs body-acceleration windows. Model: scikit-learn MLPClassifier. Chat: WebLLM.
